# Ask for a platform's folder when the card is ambiguous

Cocoon lets each system read whichever folder it is set up with, and that setup lives in Cocoon's private storage, so Loom can't see which folder Cocoon reads. Cards are often laid out by other frontends: ES-DE's template, on the AYN Thor, creates `arcade`, `mame`, `fbneo` and `fba` side by side, all empty. Loom therefore picks a platform's folder from what is on the card only when one candidate (the default plus the mapping's aliases) clearly stands out: the only one holding games, or the only one present. Otherwise it asks, at that platform's first download, and remembers the answer (as it remembers its own picks) so a platform's games keep one home. A setup step asking about every ambiguous platform up front was rejected: on an ES-DE card that is a dozen or more questions, most about systems the user never downloads.
